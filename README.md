# Poker Bro

Подсказки и обучение техасскому холдему. Всё считается прямо в браузере
на вашем устройстве — ни сервера, ни аккаунта, ни интернета после первого
открытия.

**Открыть: https://ulrikheduard.github.io/Poker-Bro/**

На iPhone: открыть в Safari, «Поделиться» → «На экран «Домой»». Дальше это
обычная иконка на экране, полноэкранный режим без адресной строки и работа
без сети.

## Что внутри

| Раздел | Что делает |
|---|---|
| **Разбор** | Раскладываете карты, которые видите за столом, и получаете шансы на победу, на поражение и на делёжку банка, шансы банка, ауты и вывод. |
| **Комбинации** | Десять комбинаций от флеш-рояля до старшей карты, с примерами и частотой встречаемости. |
| **Чарты** | С какими руками входить в игру с каждой позиции — в сетке 13×13, как их печатают везде. |
| **Словарь** | 73 термина с примерами. Все подчёркнутые слова в приложении ведут сюда. |
| **Тренажёр** | Три режима: кто сильнее на вскрытии, что делать до флопа, выгодно ли уравнять. |

## Чему здесь можно верить, а чему нет

Это важнее списка функций.

**Считается точно:** шансы на победу, шансы банка, требуемый процент на колл,
средний результат решения, ауты и вероятность их попадания, минимальная частота
защиты, порог окупаемости блефа. Это арифметика — числа не зависят ни от
оппонента, ни от манеры игры.

**Является упрощением:** сам вывод «колл / фолд / ставка» и префлоп-чарты.
Настоящее GTO-решение смешивает действия с частотами — одна и та же рука в нём
коллирует, скажем, в трети случаев, — и зависит от того, как вы играете всеми
остальными руками. Солвера здесь нет, и делать вид, что есть, нечестно. Чарты
близки к решению и, в отличие от него, запоминаются.

**Чего нет:** постфлоп-солвера, диапазонов с весами, турнирной математики (ICM).

## Как это проверено

Покерная математика — область, где легко написать правдоподобное и неверное,
поэтому всё, что можно, сверено с независимо известными числами:

- **Оценщик комбинаций** прогнан по всем 2 598 960 пятикарточным рукам.
  Количество рук каждой категории совпадает с известными значениями до единицы:
  40 стрит-флешей, 624 каре, 1 098 240 пар. Это полный перебор колоды,
  а не выборка.
- **Частоты на странице комбинаций** посчитаны перебором всех 133 784 560
  наборов из семи карт — это то, что игрок реально видит к риверу. Флеш-рояль
  из них — 4 324 набора.
- **Шансы на победу** сверены точным перебором всех 1 712 304 досок: туз с тузом
  против короля с королём даёт 82,36 % побед — ровно ту величину, которую
  печатает любой покерный калькулятор.
- **Чарты** проверяются на непротиворечивость: узкая позиция целиком входит
  в широкую, ни одна рука не стоит одновременно в двух ответах, защита
  расширяется против более широкого оппонента.
- **Ауты** считаются перебором колоды, а не по заученным числам, и карты,
  спаривающие доску, из них исключены: такую пару получает и оппонент.
- **Делёжка банка** считается как доля, а не как половина: ничья на троих
  приносит треть. «Играет доска» определяется точно — сравнением силы доски
  с силой руки вместе с ней, а не по высокой доле ничьих.
- **Русский язык** тоже под сверкой: «15 раз», а не «15 раза»; «стрит до туза»,
  а не «до туз»; «пара тузов», а не «пара тузы».

Всего 50 сверок, они же прогоняются перед каждой публикацией.

## Разработка

```bash
npm install
npm run dev       # разработка
npm run check     # 43 сверки + проверка типов
npm run build     # готовая сборка в dist/
```

Тяжёлый расчёт уходит в отдельный поток (`src/worker/`), поэтому интерфейс
не подвисает даже на точном переборе флопа — а это около миллиона досок.

```
src/engine/    расчётное ядро: карты, оценщик, эквити, ауты, шансы, чарты
src/worker/    расчёт в отдельном потоке
src/ui/        интерфейс: тема, компоненты, пять разделов
  terms.ts     связка слов в тексте со статьями словаря
```

Публикация — автоматически при пуше в `main`
(`.github/workflows/deploy.yml`): сверки, сборка, GitHub Pages.
